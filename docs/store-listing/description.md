## ショートdescription（80字以内）

## フルdescription（4000字以内）
<!-- Play Consoleの「ストアの掲載情報」→「詳しい説明」に入力 -->
CISSP Quiz は、CISSP認定試験の練習問題に取り組めるAndroidアプリです。600問の4択問題を収録し、完全オフラインで学習できます。通常モードと復習モード、知識エリア別の統計機能付き。日英両言語対応。

### 主な機能
- 600問の4択問題（6テスト × 100問）
- 全8ドメインをカバー
- 通常モード / 復習モード
- 知識エリア別の正答率統計
- 完全オフライン対応
- 日本語 / 英語切替
